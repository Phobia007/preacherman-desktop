# Preacherman font names

- 主字体 / Primary: the existing **Clash Display** (Light 300) used by the main directory and Settings. CSS token: `--demo-font-primary`.
- 2号字体 / Secondary: the existing **nbarchitekt** used by the authored Active Theory Gallery. CSS token: `--demo-font-secondary`.

These names identify existing fonts, not new replacements. Keep bundled font files, weights, spacing, and authored surface typography unchanged unless the user designates a different region. Isolated Gallery frames define their own secondary token because CSS variables do not cross iframe boundaries. Do not apply the primary font globally to the copied Gallery or Task artwork.

Future requests using “主字体” or “2号字体” refer to this mapping.
