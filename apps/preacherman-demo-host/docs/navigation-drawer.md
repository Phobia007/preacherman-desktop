# Persistent navigation drawer

The upper-left navigation uses a click-only three-line icon; startup and centered Preacherman wordmarks remain unchanged. Its transparent 48px hit target at y6/x16 keeps the original x40/y30 center aligned with the desktop controls. The SVG is40px (one-third larger than before), with no image, filled backing or hover square. The six destinations, primary font,32px menu text,68px gaps, current-page indication and charged-outline hover effect are preserved.

The drawer overlays the authored scene instead of moving or resizing pages. A solid black 288px-wide panel (16% of the authored 1800px stage) slides from the left with an interruptible 820ms cubic-bezier(.76, 0, .16, 1) transition: slow departure, acceleration, damped settling, no overshoot. A clipped surface wrapper prevents the closed panel painting into wide-window letterboxing. The menu has equal 24px side insets; every label and its hit target share the panel's x144 centerline, including on hover. The complete six-item group is vertically centered between equal 72px top and bottom insets. The charged-outline hover effect is retained without the old sideways nudge. Separate row wrappers begin a top-to-bottom fade at460ms, staggered70ms, so entry timing never delays button hover feedback. Closing fades names quickly while the panel slides away; rapid toggles reverse from the current position without mounting another panel or starting timers.

Black is the explicitly requested menu surface in both appearances, with semantic surface/edge/text/focus tokens. Only the bottom-right corner has a subtle8px radius, matching the small desktop-window corner visually; all other drawer corners stay square. The trigger itself stays transparent, using the incumbent semantic light icon/focus ink on the authored dark scenes in both appearances, like the native window controls. A transparent outside-click backdrop covers iframe content while open without dimming it. It is a sibling of the288px navigation region so it never enlarges the mouse-leave boundary. The native window controls remain above it.

Clicking the hamburger opens the drawer. Selecting destinations changes the page underneath without closing, remounting or replaying the menu reveal. Mouse movement between buttons or across blank space within the panel keeps it open; leaving the panel automatically retracts it with the existing damped transition. Merely hovering back never reopens it. Touch does not trigger mouse-leave dismissal. Click the trigger again, click outside or press Escape to close explicitly; keyboard focus returns to the trigger when appropriate, tabbing out closes the disclosure. Reduced-motion disables panel and row transitions. Overflow stays inside the menu with hidden scrollbars.

Regression checks cover both appearances, white-background occlusion, all six destinations, geometry, transition acceleration/deceleration, stagger ordering, interrupted reversal, outside-click isolation, keyboard/Escape, reduced motion and the native desktop controls. Production deployment follows the desktop lightweight update contract.
