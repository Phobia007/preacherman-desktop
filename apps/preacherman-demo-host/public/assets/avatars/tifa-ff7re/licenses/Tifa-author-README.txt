FFVII REMAKE Tifa Rig v1


This file contains Tifa Lockhart Rig (Default Outfit from FFVII Remake) and is compatible with Blender 4.1+ (Should work fine in Cycles).

This is a custom Rigify rig. If you are familiar with Rigify, most of the controls and UI should look familiar!

The UI should be visible by default, but in case you don't see it, just run the script file in the text editor.

Her face is custom but should also be very straightforward to animate.

The main layer contains the action controls + master controls that should be good to make the majority of her expressions, but you also

have access to all the other primary and secondary controls.

Hair Rig is a basic stretchy FK chain with a Master control for the back Hair to help with collisions.

Skirt has a fake collision mechanism to help avoid intersections + FK, Tweak, and Master controls.

Fingers also have FK/IK switch and master controls.

All the relevant properties should be visible on the UI if you select any control relevant to that property.
