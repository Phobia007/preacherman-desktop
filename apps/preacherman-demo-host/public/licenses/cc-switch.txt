CC Switch UI adaptations

Retrieved: 2026-09-05

Preacherman retains the preset-to-form interaction and controlled masked key
input. Tailwind, i18n and icon dependencies are adapted to local semantic CSS,
locale strings and inline icons. Provider presets are limited to the existing
Preacherman backend. CC Switch's database, application switching, credentials,
native commands and configuration files are not imported or modified.
