# Page topology

1. Shared Preacherman shell and persistent Cortana model remain behind the Gallery layer.
2. Gallery reveal layer draws a white horizontal line, pulses open partially, then expands upward and downward to expose the page.
3. The source portfolio runs in a same-origin transparent iframe using its original WebGL scene and DOM HUD.
4. Featured contains the original eight-card curved horizontal rail driven by wheel, pointer drag, and touch.
5. Profile is the original click-driven center information state.
6. Featured / Full is the original bottom-left view switcher; Full preserves the original project index.
7. The source top-left name and WebGL background/grid are intentionally absent.
